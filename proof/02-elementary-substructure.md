# 構造と初等部分構造

前提: [01 順序数と ω₁](01-ordinals.md)

## 1. 言語と構造

**定義（言語）.** 以下で使う言語 $`\mathcal{L}_N`$ は、2 項関係記号 $`\le, \le_1, \dots, \le_N`$ だけからなる。

**定義（構造）.** $`\mathcal{L}_N`$ の構造とは、集合 $`M`$ と、$`M`$ 上の 2 項関係 $`N + 1`$ 個の組である。それぞれが記号 $`\le, \le_1, \dots, \le_N`$ の意味になる。

**記法.** 集合 $`M`$ と、$`M`$ 上の 2 項関係 $`P_0, P_1, \dots, P_N`$ からなる構造を

```math
(M;\ P_0, P_1, \dots, P_N)
```

と書く。セミコロンの前の $`M`$ を構造の **宇宙** と呼ぶ。論理式の量化子が走る範囲である。セミコロンの後ろは、記号 $`\le, \le_1, \dots, \le_N`$ に順に割り当てる関係である。

関係が宇宙より広い範囲で定義されているときは、宇宙の元どうしの組だけを残した関係（制限）を使う。

**例.** 関係 $`R`$ を $`a \mathrel{R} b \iff b = a + 1`$ とする。構造 $`(3;\ \le, R)`$ は次のとおりである（[01](01-ordinals.md) §1 のとおり、$`3`$ は $`3`$ 未満の順序数全体 $`\{0, 1, 2\}`$ のことである）。

| 部分 | 中身 |
|---|---|
| 宇宙 | $`\{0, 1, 2\}`$ |
| $`\le`$ の意味 | $`0 \le 0,\ 0 \le 1,\ 0 \le 2,\ 1 \le 1,\ 1 \le 2,\ 2 \le 2`$ |
| $`\le_1`$ の意味 | $`0 \mathrel{R} 1,\ 1 \mathrel{R} 2`$ |

$`2 \mathrel{R} 3`$ は、$`3`$ が宇宙に入っていないので、この構造には現れない。構造 $`(4;\ \le, R)`$ では現れる。

このノート以降で使う構造は、すべて次の形をしている。順序数全体の上の 2 項関係 $`R_1, \dots, R_N`$ を 1 組決めておき、順序数 $`\alpha`$ ごとに

```math
(\alpha;\ \le,\ R_1, \dots, R_N)
```

を考える。宇宙は $`\alpha`$ 未満の順序数全体で、関係は全体の関係を $`\alpha`$ 未満に制限したものである。

**定義（部分構造）.** $`\alpha \le \beta`$ のとき、$`(\alpha; \le, R_1, \dots, R_N)`$ は $`(\beta; \le, R_1, \dots, R_N)`$ の **部分構造** である。$`\alpha`$ 未満の 2 元の間の関係は、どちらの構造で見ても同じだからである。

## 2. 論理式

原子式は $`x \le y`$ と $`x \le_j y`$ である。$`x = y`$ は $`x \le y \wedge y \le x`$、$`x \lt y`$ は $`\neg\, y \le x`$ で書ける。

量化子を含まない論理式を **量化子なし論理式** と呼ぶ。量化子なし論理式 $`\psi`$ に、$`\exists`$ から始まって交互に並んだ $`n`$ 個の量化子ブロックを付けた論理式を **$`\Sigma_n`$ 論理式** と呼ぶ。

```math
\exists \vec x_1\ \forall \vec x_2\ \exists \vec x_3 \cdots\ \psi
```

$`\forall`$ から始まるものは **$`\Pi_n`$ 論理式** と呼ぶ。$`\Sigma_n`$ 論理式の否定は $`\Pi_n`$ 論理式と同値である。ブロックが $`n`$ 個より少ない論理式も、空のブロックを足せば $`\Sigma_n`$ 論理式とみなせる。

| 論理式 | 形 | 意味 |
|---|---|---|
| $`\exists x\ (p \lt x)`$ | $`\Sigma_1`$ | $`p`$ より大きい元がある |
| $`\exists x\ \forall y\ (y \le x)`$ | $`\Sigma_2`$ | 最大元がある |
| $`\forall x\ \exists y\ (x \lt y)`$ | $`\Pi_2`$ | 最大元が無い |
| $`\exists x\ \exists y\ (x \lt y \wedge x \le_1 y)`$ | $`\Sigma_1`$ | $`\le_1`$ で結ばれた異なる 2 元がある |

## 3. 充足と、上下への保存

$`M \models \varphi[\vec p]`$ は、$`M`$ の元の組 $`\vec p`$ をパラメータとして入れた $`\varphi`$ が、$`M`$ で成り立つことを表す。量化子は $`M`$ の元だけを走る。

**補題.** $`M`$ を $`M'`$ の部分構造、$`\vec p`$ を $`M`$ の元の組とする。

1. 量化子なし論理式の真偽は、$`M`$ と $`M'`$ で同じである
2. $`\Sigma_1`$ 論理式が $`M`$ で真なら、$`M'`$ でも真である（上へ保存）
3. $`\Pi_1`$ 論理式が $`M'`$ で真なら、$`M`$ でも真である（下へ保存）

**証明.** 1 は原子式の真偽が同じことから出る。2 は、$`M`$ の中の証人がそのまま $`M'`$ の中の証人になる。3 は 2 の対偶である。$`\square`$

$`\Sigma_2`$ 論理式は、どちらの向きにも保存されるとは限らない。関係 $`\le`$ だけの構造で、「最大元がある」は $`(\omega + 1; \le)`$ で真、$`(\omega; \le)`$ で偽である。

## 4. Σₙ 初等部分構造

**定義.** $`M`$ が $`M'`$ の部分構造であり、$`M`$ の元をパラメータとするすべての $`\Sigma_n`$ 論理式 $`\varphi`$ について

```math
M \models \varphi[\vec p] \iff M' \models \varphi[\vec p]
```

が成り立つとき、$`M \preceq_{\Sigma_n} M'`$ と書き、$`M`$ は $`M'`$ の **$`\Sigma_n`$ 初等部分構造** であるという。

次がすぐ分かる。

- $`M \preceq_{\Sigma_{n+1}} M'`$ なら $`M \preceq_{\Sigma_n} M'`$ である
- $`M \subseteq M' \subseteq M''`$ で $`M \preceq_{\Sigma_n} M'`$ かつ $`M' \preceq_{\Sigma_n} M''`$ なら、$`M \preceq_{\Sigma_n} M''`$ である
- 否定を取れば、$`\Pi_n`$ 論理式の真偽も一致する

### 4.1 例（関係 ≤ だけの構造）

| 構造の組 | 結果 | 理由 |
|---|---|---|
| $`(3; \le)`$ と $`(4; \le)`$ | $`\Sigma_1`$ 初等部分構造でない | $`\exists x\ (2 \lt x)`$ が $`4`$ で真、$`3`$ で偽 |
| $`(\omega; \le)`$ と $`(\omega + 1; \le)`$ | $`\Sigma_1`$ 初等部分構造 | 4.2 の例 |
| $`(\omega; \le)`$ と $`(\omega + 1; \le)`$ | $`\Sigma_2`$ 初等部分構造でない | 「最大元がある」 |

### 4.2 Σ₁ 初等部分構造は、有限個の点のコピーで決まる

**命題.** 言語が有限個の関係記号だけからなるとする。$`M`$ を $`M'`$ の部分構造とする。次は同値である。

1. $`M \preceq_{\Sigma_1} M'`$
2. $`M`$ の有限部分集合 $`X`$ と、$`M'`$ の有限部分集合 $`Y`$ に対し、$`M`$ の有限部分集合 $`Y'`$ と全単射 $`h : X \cup Y' \to X \cup Y`$ で、$`X`$ の元を動かさず、すべての原子式の真偽を保つものがある

**証明.** 1 から 2：$`Y = \{y_1, \dots, y_s\}`$ とする。「$`X`$ と $`u_1, \dots, u_s`$ の間の原子式の真偽が、$`X`$ と $`y_1, \dots, y_s`$ の間のものと同じ」は、関係記号が有限個なので量化子なし論理式で書ける。これに $`\exists u_1 \cdots \exists u_s`$ を付けた $`\Sigma_1`$ 論理式は $`M'`$ で真なので、$`M`$ でも真であり、その証人が $`Y'`$ である。

2 から 1：$`\Sigma_1`$ 論理式 $`\exists \vec u\ \psi(\vec p, \vec u)`$ が $`M'`$ で真なら、証人の集合を $`Y`$、パラメータの集合を $`X`$ としてコピー $`Y'`$ を取る。原子式の真偽が同じなので、$`\psi`$ は $`Y'`$ でも真である。上へ保存と合わせて 1 を得る。$`\square`$

**例.** $`(\omega; \le)`$ と $`(\omega + 1; \le)`$ では、$`Y`$ に $`\omega`$ が入っていれば、それを $`X \cup Y`$ の自然数の最大値より大きい自然数に取り替えればコピーになる。

このコピーの考え方が、[06](06-finite-reflection.md) の有限反映の原型である。

## 5. Lean での書き方

Lean では論理式を構文として定義しない。次のように、値の側で表す。

**原子図式.** 順序数の列 $`v = (v_0, v_1, \dots)`$ の最初の $`n`$ 個の **原子図式** を、次のように置く。$`[P]`$ は $`P`$ の真偽である。

```math
\mathrm{diag}_n(v)(a, b) = \bigl([v_a \le v_b],\ [v_a \le_1 v_b],\ \dots,\ [v_a \le_N v_b]\bigr) \qquad (a, b \lt n)
```

**例.** $`N = 1`$ とし、記号 $`\le_1`$ の意味 $`R_1`$ を、例として次の関係にする。

```math
a \mathrel{R_1} b \iff a = b \vee \bigl(a \text{ は極限順序数で } b = a + 1\bigr)
```

列 $`v = (3,\ \omega,\ \omega + 1)`$ の最初の $`3`$ 個の原子図式は、次の表になる。各成分は $`([v_a \le v_b],\ [v_a \mathrel{R_1} v_b])`$ で、$`1`$ が真、$`0`$ が偽である。

| | $`b = 0`$（$`3`$） | $`b = 1`$（$`\omega`$） | $`b = 2`$（$`\omega + 1`$） |
|---|---|---|---|
| $`a = 0`$（$`3`$） | $`(1, 1)`$ | $`(1, 0)`$ | $`(1, 0)`$ |
| $`a = 1`$（$`\omega`$） | $`(0, 0)`$ | $`(1, 1)`$ | $`(1, 1)`$ |
| $`a = 2`$（$`\omega + 1`$） | $`(0, 0)`$ | $`(0, 0)`$ | $`(1, 1)`$ |

- 列 $`w = (5,\ \omega \cdot 2,\ \omega \cdot 2 + 1)`$ の原子図式は、この表と同じである
- 列 $`u = (3,\ \omega,\ \omega + 2)`$ の原子図式は、$`(a, b) = (1, 2)`$ の成分が $`(1, 0)`$ になるので、この表と違う

量化子なし論理式の真偽は、変数に入れた値の原子図式だけで決まる。原子図式は有限種類しかないので、量化子なし論理式は **原子図式の集合 $`D`$** と同じ情報を持つ。

**例（続き）.** 量化子なし論理式 $`\psi(x, y, z) = x \lt y \wedge y \mathrel{R_1} z`$ は、$`v`$ と $`w`$ を入れると真、$`u`$ を入れると偽である。$`\psi`$ に対応する $`D`$ は、「位置 $`(1, 0)`$ の $`\le`$ の成分が $`0`$、位置 $`(1, 2)`$ の $`R_1`$ の成分が $`1`$」を満たす原子図式全体である。$`x \lt y`$ は $`\neg\, y \le x`$ だからである。

**ブロックによる評価.** 量化子ブロックの長さの列 $`[b_1, \dots, b_r]`$、原子図式の集合 $`D`$、パラメータの列を与えて、$`\mathrm{Sig}_M`$ をブロックの数についての再帰で定める。

```math
\mathrm{Sig}_M([\,],\ v) \iff \mathrm{diag}_n(v) \in D
```

```math
\mathrm{Sig}_M([b_1, b_2, \dots, b_r],\ v) \iff \exists x_0, \dots, x_{b_1 - 1} \lt M\ \ \neg\, \mathrm{Sig}_M([b_2, \dots, b_r],\ v\,\vec x)
```

ここで $`v\,\vec x`$ は、すでに値を入れた位置の後ろに $`x_0, \dots, x_{b_1 - 1}`$ を並べた列である。$`n`$ はパラメータの個数と $`b_1 + \cdots + b_r`$ の和にとる。展開すると次の形になる。

```math
\mathrm{Sig}_M([b_1, \dots, b_r],\ \vec p) \iff \exists \vec x_1\ \neg\, \exists \vec x_2\ \neg \cdots \exists \vec x_r\ \neg\, \bigl(\mathrm{diag}(\vec p, \vec x_1, \dots, \vec x_r) \in D\bigr)
```

$`\neg \exists = \forall \neg`$ なので、これは $`\exists \vec x_1\ \forall \vec x_2\ \exists \vec x_3 \cdots`$ の形の $`\Sigma_r`$ 論理式であり、行列部分は $`D`$ かその補集合である。逆に、どの $`\Sigma_r`$ 論理式もこの形に書ける。

**例.** 「最大元がある」は、パラメータ無し、ブロック $`[1, 1]`$、$`D = \{d : d(1, 0)`$ の $`\le`$ の成分が真$`\}`$ で表せる。

```math
\mathrm{Sig}_M([1, 1],\ ()) \iff \exists x\ \neg\, \exists y\ \neg\, (y \le x) \iff \exists x\ \forall y\ (y \le x)
```

**Σⱼ 初等部分構造.** $`\mathrm{Elem}_j(\alpha, \beta)`$ を、「ブロックが $`j`$ 個以下のすべての列、すべての $`D`$、$`\alpha`$ 未満のすべてのパラメータについて、$`\mathrm{Sig}_\alpha`$ と $`\mathrm{Sig}_\beta`$ が一致する」ことと定める。これは $`(\alpha; \ldots) \preceq_{\Sigma_j} (\beta; \ldots)`$ と同じ意味である。
