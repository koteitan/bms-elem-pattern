Status

  • 1 and 2 rows: the translation keeps the order of matrices (see Why the order is kept).
  • 3 rows: the output is a respecting forest of order 3. The order is kept for the least ordinal that can label the last column, but it is not known whether that labelling is an exact copy of the output.
  • 4 rows and more: not supported.
  • Standard matrices are assumed.

Rule

Every column is a node, and the ancestors of a column give the relations:

  • column j is a k-ancestor of column i ⇒ node j <k+1 node i, and nothing else is related.
  • The k-parent of a column is the rightmost candidate with a smaller entry in row k. The candidates are all columns to the left for k = 0, and the (k−1)-ancestors for k ≥ 1 (BM4). A k-ancestor is reached by following k-parents.
  • The relations are those of Carlson's structure RN = (Ord; ≤, ≤1, …, ≤N), where α ≤i β means (α; ≤, ≤1, …) is a Σi-elementary substructure of (β; ≤, ≤1, …).

Output

  • Nodes are named a, b, c, … from left to right, one per column.
  • x(p): p is the largest node with p <1 x. x(p,q) adds the largest q with q <2 x, and x(p,q,r) the largest r with r <3 x. The full relations are generated from these links.
  • point is the last node.

Example: (0,0)(1,1)(2,1) → a b(a,a) c(b,a) point: c, that is a <1 b <1 c, a <2 b, a <2 c, and b and c are not related by ≤2.

The point does not denote the value of the matrix. For example (0,0)(1,1) gives a b(a,a), a pair a <2 b, whose least realization is ε0·ω <2 ε0·(ω+1), while the value of the matrix is ε0. The additive version aims at the value itself.

Why the order is kept

  1. A stable label of a matrix assigns increasing ordinals to its columns so that a k-ancestor gets an ordinal <k+1 the ordinal of the column. This is a covering of the output pattern.
  2. DH, Proposition 19.1: if a matrix A has a stable label f and A[n] is not empty, then A[n] has a stable label g whose last value is smaller than the last value of f. It needs finite reflection for the relations, which holds for <1, <2 in R2 and for <1, <2, <3 in R3 (proof, 3 rows, Lean).
  3. Wilken, Pure patterns of order 2, Theorems 4.3, 4.4 and Corollary 4.8: every respecting forest of order 2 has a unique isominimal realization, and it is pointwise below every covering.
  4. By 2 and 3, the least realization of the last node of A[n] is below the last value of g, which is below the least realization of the last node of A. So every expansion lowers the point.
  5. If A < B are standard, some B[n] is ≥ A; repeating this reaches A from B by expansions. This step is only checked, not proved here (see Checks).

For 3 rows, steps 1, 2 and 5 still work, so the least ordinal that can label the last column keeps the order. Step 3 is not known for order 3.

Checks

  • Respecting forests (≤k+1 ⊆ ≤k, and p ≤k q ≤k r with p ≤k+1 r implies p ≤k+1 q): all 44653 standard 2-row matrices with at most 8 columns and all 13628 standard 3-row matrices with at most 6 columns.
  • Step 5: all 824970 pairs of standard 2-row matrices with at most 6 columns and all 924120 pairs of standard 3-row matrices with at most 5 columns (expansion BM4, standardness by yaBMS).
  • 1 row: with Carlson's formula for ≤1 below ε0, the columns of every standard primitive sequence of length at most 9 (1204 sequences) can be placed so that the relations match exactly and the points increase; for a sequence with one root, the first column is placed at the value of the sequence.

Input

  • One matrix per line; all lines are translated.
  • Characters other than (),0-9 are ignored. Shorter columns are padded with 0, and rows of zeros at the bottom are dropped.
  • The input is mirrored to the URL query ?bms=.
